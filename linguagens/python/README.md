## O que é

Python é uma linguagem **interpretada**, famosa por ser fácil de ler. É a linguagem principal de **dados e inteligência artificial**, e muito usada em **back-end** e **automação**. Leia o **[sobre o Python](sobre.md)**: história, onde se usa, frameworks e o que os cursos raramente contam.

## Antes de começar

- [ ] Ler os [fundamentos](../../fundamentos/)
- [ ] Ter feito (ou estar fazendo) a [lógica de programação](../../disciplinas/logica/), que já tem exemplos em Python
- [ ] Instalar: [Windows](instalacao/windows.md) · [Mac](instalacao/mac.md)
