# 01 · Olá, Java

> Nível: ⭐ · Assuntos: estrutura de um programa · Criado por: @clehdev

## Enunciado

Escreva um programa em Java que mostre:

```
Ola, Java!
```

## Entrada

Nenhuma.

## Saída

Exatamente `Ola, Java!`, seguido de uma quebra de linha.

## 💡 Dicas

<details>
<summary>Dica 1</summary>

Veja o "Olá, mundo" explicado palavra por palavra no material [primeiro programa](../../material/01-primeiro-programa.md).

</details>

<details>
<summary>Dica 2</summary>

O arquivo se chama `seu-username.java`, e a classe pode se chamar `Main`. Teste com `java seu-username.java`.

</details>
