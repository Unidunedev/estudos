# 02 · Soma de dois números

> Nível: ⭐ · Assuntos: variáveis, scanf, printf · Criado por: @clehdev

## Enunciado

Leia dois números inteiros e mostre a soma deles.

## Entrada

Dois números inteiros, um por linha.

## Saída

A soma dos dois, seguida de uma quebra de linha.

## Exemplos

| Entrada | Saída |
|---|---|
| `3`<br>`5` | `8` |
| `-10`<br>`4` | `-6` |

## 💡 Dicas

<details>
<summary>Dica 1</summary>

Para ler um inteiro: `scanf("%d", &a);`. Não esqueça o `&`!

</details>

<details>
<summary>Dica 2</summary>

Não mostre mensagens como `Digite o primeiro numero:`. A correção compara só a resposta.

</details>
