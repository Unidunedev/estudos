# 02 · O maior de três

> Nível: ⭐ · Assuntos: condicionais, operadores lógicos · Criado por: @clehdev · Linguagens: C, Python ou Java

## Enunciado

Leia três números inteiros e mostre o maior deles.

## Entrada

Três números inteiros, um por linha. Podem ser negativos e podem se repetir.

## Saída

O maior número.

## Exemplos

| Entrada | Saída |
|---|---|
| `3`<br>`9`<br>`5` | `9` |
| `-5`<br>`-2`<br>`-9` | `-2` |

<summary>Dica 1</summary>

Uma estratégia: guarde o primeiro como "maior até agora" e compare com os outros, um de cada vez.
